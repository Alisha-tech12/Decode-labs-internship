# Project 2: Iris Flower Classification Using K-Nearest Neighbors

A supervised machine learning project that classifies Iris flowers into three species (Setosa, Versicolor, Virginica) based on sepal and petal measurements using the K-Nearest Neighbors algorithm.

## Overview

This project demonstrates the fundamental concepts of supervised learning including data exploration, train-test splitting, feature scaling, model training, and performance evaluation. The Iris dataset is used as it is a standard benchmark dataset in machine learning.

## Dataset

| Property | Value |
|----------|-------|
| Name | Iris Dataset (built into scikit-learn) |
| Samples | 150 (50 per species) |
| Features | 4 (sepal length, sepal width, petal length, petal width) |
| Target Classes | Setosa (0), Versicolor (1), Virginica (2) |

### Feature Description

- Sepal length: Length of the outer flower part (cm)
- Sepal width: Width of the outer flower part (cm)
- Petal length: Length of the inner flower part (cm)
- Petal width: Width of the inner flower part (cm)
